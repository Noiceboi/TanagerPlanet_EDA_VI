Zhang-Suen (left) vs CAT (right) — CAT handles width variation smoothly
Why CAT? Zhang-Suen pixel thinning produces staircase artifacts at 45° and loses scale information. CAT uses Delaunay triangulation to encode local canal width in each triangle's circumradius. Wide rivers → Junction clusters (red) → smooth branching nodes. Narrow canals → Sleeve chains (blue) → precise 1-triangle-wide centerlines. Width transitions between river and tributary are handled continuously with no artifacts. Adaptive pruning threshold = 1.5 × local_radius (from EDT) — wide junctions tolerate longer spurs.

Methodology
1
Threshold Segmentation
Percentile-based cut on the VI map (P88 for high-water indices, P12 for MSI). Simple and fast — establishes a spectral prior for what "looks like water" in each band.
2
Geometric Segmentation
Frangi filter (σ = 2–16 px) detects elongated tubular structures (kênh rạch). LoG blob (σ = 4–20 px) detects round ponds/lakes. Combined 60/40 with VI prior to suppress false positives.
3
Skeleton / Centerlines
Zhang-Suen (parallel thinning): all pixels removed simultaneously per iteration. Fast, produces clean 1-px skeleton but creates 45° staircase artifacts at diagonal segments.
4
Chordal Axis Transform
Delaunay triangulation of the boundary contour → classify triangles (Terminal/Sleeve/Junction) → build midpoint axis. Adaptive pruning: threshold = 1.5 × local_radius (EDT). Wide rivers tolerate longer spurs; narrow canals prune aggressively. Taubin smoothing (λ=0.5, μ=−0.53) removes staircase without shrinking the curve.
